# Akshay S Salesforce Portfolio

Portfolio adapted from Abinav S’s editorial portfolio design, with Akshay’s Salesforce experience and contact information. The resume PDF is private; resume buttons open an email request instead.

## Local preview

Run `python -m http.server 8000 --directory site` and visit http://localhost:8000.

## GitHub Pages

Push to the `main` branch of `Akshayy-18/akshay-s-salesforce-portfolio`.
In the repository, open Settings → Pages and select **GitHub Actions** as the source.
Run the Deploy portfolio to GitHub Pages workflow or push a new commit.
Expected project URL after successful deployment: https://akshayy-18.github.io/akshay-s-salesforce-portfolio/

The website uses relative paths, so it works at a repository subpath. No framework build or third-party runtime dependencies are needed.
All public files are under `site/`. The workflow deploys only this folder.
